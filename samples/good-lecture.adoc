= Kubernetes Fundamentals

== Overview

In this lecture you will learn about Kubernetes.
Kubernetes is a container orchestration platform.
This platform allows you to deploy and manage containerized applications at scale.

== What is Kubernetes?

Kubernetes (often abbreviated as k8s) is an open-source container orchestration system.
It was originally designed by Google and is now maintained by the Cloud Native Computing Foundation.

The following list shows some key features:

* Automated deployment
* Self-healing capabilities
* Load balancing
* Service discovery

=== Architecture

Kubernetes uses a primary-secondary architecture.
The control plane manages the worker nodes.
You can use Kubernetes to:

* Deploy applications
* Scale applications
* Monitor applications

IMPORTANT: Make sure you have kubectl installed on your workstation.

== Getting Started

Follow these steps:

. Install Docker on your machine
. Install kubectl CLI tool
. Set up a local cluster using minikube
. Deploy your first application

NOTE: This is just a quick introduction. Refer to the official documentation for more details.

=== Common Commands

Some commands for working with Kubernetes:

[source,bash]
----
kubectl get pods
kubectl describe pod mypod
kubectl delete pod mypod
----

You will use these commands when working with Kubernetes.
