{%- comment -%} Do not use // line comments in this file. just-the-docs renders every page through _layouts/vendor/compress.html, which strips newlines and ships the document as a single line. Any // comment in an inline script therefore swallows the entire rest of the script — including the code — and the browser reports no error, because a comment is valid syntax. That silently disabled this script the first time it shipped. Block comments survive the collapse; line comments do not. {%- endcomment -%}
